Útmutató-asszisztens – forráskód és működés

RAG-rendszer magyar használati útmutatókhoz: FastAPI + Postgres/pgvector + React, Dockerben, OpenRouter-modellekkel. Itt megtalálod, hogyan indítsd, mit állíthatsz be, hogyan halad egy dokumentum és egy kérdés a rendszeren át – minden kódrész fájlnévvel és sorszámmal.

🐍 Python 3.12 · FastAPI🐘 Postgres 16 + pgvector⚛️ React 18 + Vite + TS🔭 Phoenix🐳 Docker · WSL📦 github.com/akicsike/utmutato-asszisztens

Ha valami nem megy

„Repository not found” vagy 403 a klónozásnál

A repóhoz nincs hozzáférésed: fogadd el a meghívót (GitHub → Notifications), és ellenőrizd, hogy azzal a fiókkal / tokennel lépsz be, amelyik meghívást kapott. Tokennél a Contents: Read jog és a repó kiválasztása kell.

„permission denied … docker.sock”

Docker Desktopnál kapcsold be a WSL integrációt az Ubuntuhoz; Docker Engine-nél add a felhasználót a docker csoporthoz: sudo usermod -aG docker $USER, majd nyiss új terminált.

„port is already allocated”

A port foglalt: a .env-ben állíts másikat – API_PORT, POSTGRES_PORT, PHOENIX_PORT –, majd docker compose up -d.

„password authentication failed” a Postgres-naplóban

A POSTGRES_PASSWORD-ot az első indítás után átírtad, de a DB a régit őrzi. Állítsd vissza a régire – vagy (ha nincs megőrzendő adat) docker compose down -v és újraindítás.

A beolvasás „hiba” állapotú, vagy 401 az OpenRoutertől

Ellenőrizd az OPENROUTER_API_KEY-t és a kreditet; a pontos hiba: docker compose logs worker. Javítás után a Dokumentumok fülön Újrafeldolgozás.

Gyakori módosítások

Másik LLM a válaszhoz

.env: CHAT_MODEL=anthropic/claude-… (bármely OpenRouter-modell) → docker compose up -d. A költség automatikusan naplózódik.

Másik embedding-modell

EMBED_MODEL átírása → up -d → admin: Mind újraindexelése (az új modell vektorai elkészülnek; a régiek a táblában maradnak).

A válasz stílusának / szabályainak módosítása

backend/app/rag/prompts/system.md → docker compose build api && docker compose up -d api → prompt_eval.py-val ellenőrizd, hogy nem romlott.

Szigorúbb / lazább keresés

RERANK_MIN_SCORE (magasabb = több „nem találtam”, kevesebb tévedés), TOP_K (több forrás = teljesebb, de drágább válasz), RERANK_CANDIDATES (költség!). Utána rag_eval.py.

Új chunk-stratégia

Hibaelhárítás – amibe a projekt során belefutottam

Az api nem indul: „password authentication failed”

A POSTGRES_PASSWORD az első induláskor rögzül a pg_data kötetben; a .env későbbi módosítását a DB nem veszi át. Javítás: a konténerben ALTER USER az új jelszóra (a jelszót ne írd ki – psql-változóként add át).

Szkennelt PDF-ből nem jön ki szöveg

A docling-parse backend egyes PDF-eknél üres oldalképet ad az OCR-nek („Too few characters”). Ezért képalapú oldalnál PyPdfiumDocumentBackend (parser.py). Ellenőrzés: rendereld az oldalt pypdfium2-vel PNG-be.

„Permission denied” rsync-nél az eval/ vagy data/ mappán

A Docker root-ként hozta létre a bind-mount mappát. docker run --rm -v $PWD/eval:/e alpine chown -R $(id -u):$(id -g) /e.

A Phoenix tele van képletöltés- és /health-trace-szel

A FastAPI 0.16x beépített OpenTelemetry-je minden kérést trace-el; szűrés: FastAPI(telemetry={"exclude": …}) (main.py). Az OTEL_PYTHON_FASTAPI_EXCLUDED_URLS erre nem hat.

Egy docker compose exec-et tartalmazó, stdin-ről futtatott szkript félúton „elhal”

Az exec -T elnyeli a szkript maradékát a stdin-ről. Fájlból futtasd, vagy adj < /dev/null-t az exec-nek.
